# Changelog

## 0.1.0 — 2026-08-30

First public release.

- Added an explicit, evidence-aware workflow for finding distinct practical routes around a blocker.
- Added 60 evaluation cases, 24 explicit-invocation cases, an eight-case high-friction panel, a blinded evaluation protocol, and deterministic validation tooling.
- Added a one-command Codex installation path and English/Russian README files.
- Kept the skill explicit-only: it researches and recommends, but never takes external action by default.

This version makes no outcome-quality or token-efficiency claim. Those require the published baseline-versus-skill evaluation described in `evals/`.
