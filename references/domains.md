# Domain routing

Read the chosen section and Access / Delegation when relevant.

## Common

Cover direct/manual, reuse/adapt, buy/hire/delegate, combine, automate/build, remove/defer/no-action, reversible diagnostic, recovery/rollback, closest precedent/failure, transfer, and drift from the original outcome. Default exploration order: entitlement/delegation → direct/manual → reuse/adapt → buy/hire → combine → automate → build → remove/defer.

## Local / Procurement

Verify official offer, all-in cost, restrictions/cancellation, time/logistics, and exact channel. Aggregators discover; direct current source establishes availability. Include online/message/call/concierge/visit, no-call route, and fallback. Record `option | status | total cost | friction | route | checked | gap`.

## Technical / System

Map `trigger → entry → dependencies → state → concurrency → I/O → output → tests → observability`. Cover baseline, elimination, reuse/OSS, fixtures/cache/fakes, scheduling, determinism, boundaries, owner/tooling, rollback, and no-change. Gains remain hypotheses until measured.

## Process / Operations

Map `input → triage → rights → handoffs → queue → execution → feedback → review`; inspect WIP, waiting, rework, approvals, ownership, incentives, SLOs, recovery, and decision rights. Prefer reversible pilots before broad policy changes.

## Market / Product

Map `segment → job → current alternative → offer → channel → conversion → delivery → retention → economics`. Cover manual/concierge/presale/fake-door evidence, reuse/buy/partner/no-build, access, proof, capacity, and stop rules before custom product.

## General / Decision

Separate symptom, cause, constraint, and desired outcome. Cover environment, incentives, sequence/scope, capability acquisition, delegation, reuse, automation, removal, and the cheapest diagnostic.

## Access / Delegation

Check support, benefits, concierge, assistant, expert/vendor, marketplace, trusted contact, and automation. Draft only: `delegate | request | inputs | channel | response artifact | cost/risk | fallback`.
