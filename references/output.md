# Output contract

Lead with the decision, not the method.

Ordinary complete answers need no length target. If a completed draft exceeds roughly 1,600 words, trim only repetition, process narration, optional deep-pack prose already represented in a route row, and lower-ranked detail that cannot change the choice. Never trim any first-five route's mechanism, owner/action, artifact/signal, continue/stop or rollback, fallback, or evidence boundary.

1. **Bottom line:** name the best overall route, the criteria it wins on, and the condition that would make another route win. Add easiest, cheapest credible, highest-confidence, or first diagnostic only when genuinely different. When two or more routes are plausible, compare only the leaders in one compact scorecard using the user's criteria; otherwise use `constraint fit | evidence | time/cost | reversibility | information gain`.
2. **Problem model:** outcome, constraints, attempts, key facts/assumptions, competing causes, and decisive unknowns.
3. **Compiled ranked map:** return the exact viable set—one route for a narrow task, commonly 3–7 for bounded choices, and usually no more than 5–12 for an open or stuck task. Each of the first five rows is independently actionable in one or two compact lines: `mechanism | owner:first action | artifact/signal + decision threshold | continue/stop or rollback | fallback | fit/evidence | why this rank`. Keep the fields in that row; a later paragraph cannot repair it. Do not place two routes with one mechanism in the first five unless their constraint world or fallback role differs materially.
4. **Optional deep pack:** expand only the selected route or a genuinely different conditional winner when execution requires a multi-step handoff. Add only details absent from the compiled row: dependencies, sequence, falsifier, and copy-ready handoff prompt.
5. **Negative evidence and gaps:** failed cases, rejected families, disconfirmers, unavailable sources, and facts that could change rank.
6. **Saturation:** one short reason the last meaningful pass could not change the decision.

Do not create quotas for transfers, source types, or number of ideas. A strong transfer competes in the ranked map like any other route. Do not expose brainstorming, pre-mortem, inversion, scale shift, research, benchmarking, or analogy search as a solution unless compiled into a concrete route with an enabled decision. Do not repeat a compiled row in paragraph form.
