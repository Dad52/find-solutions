# Find Solutions

[English](README.md)

> Find Solutions помогает найти рабочее решение, когда очевидные варианты уже отпали.

Это ручной скилл только для исследования — на случай, когда задача правда
застряла. Он держит в голове цель и жёсткие ограничения, не выдаёт за новое
решение переименованную неудачную попытку и возвращает конкретный следующий
шаг с сигналом, стоп-правилом и fallback.

Вызывай его, когда новые идеи только раздуют список. Не вызывай для обычной
задачи с очевидным ответом или чтобы что-то сделать снаружи: он может изучить
варианты и посоветовать, но не будет деплоить, писать, бронировать, покупать
или кому-то звонить.

## Что показал бенчмарк

В 15 парных прогонах со слепой оценкой Find Solutions **14 раз** поставил на
первое место правильный путь; обычный Codex — **9 раз**. У него также меньше
ловушек и ответов с нарушением жёсткого ограничения. При этом оба варианта
нашли хотя бы один пригодный путь в каждом прогоне.

| Метрика | Обычный Codex | С Find Solutions |
| --- | ---: | ---: |
| Верный первый путь | 9 / 15 | **14 / 15** |
| Маршрутов-ловушек | 15 | **11** |
| Ответов хотя бы с одним нарушением ограничения | 6 / 15 | **4 / 15** |
| Практичных путей, среднее из пяти | 2,53 | 2,60 |
| Медиана времени ответа | **21,9 с** | 22,8 с |
| Среднее выходных токенов | **986** | 1 112 |

Скилл улучшает первый выбор, а не скорость или краткость. [В полном отчёте](docs/benchmarks/2026-08-30/find-solutions-head-to-head.md) есть кейсы, шкала, контрпримеры и три отобранные пары ответов.

## Как это выглядит на практике

| Ситуация | Без скилла | С Find Solutions |
| --- | --- | --- |
| Дождливая суббота и травмированное колено | В запасном маршруте не проверена дорога домой; добавлен неполный вариант только с рынком. | Запасной маршрут зависит от всех переездов, мест для сидения, суммарной ходьбы и дороги домой. |
| Week‑2 retention и обманчивая корреляция | Эксперимент разумный, но fallback предполагает несуществующую функцию и неподтверждённый факт о приватности. | Маленький эксперимент с permissions, guardrail по результату и отдельный путь для сбора доказательств без притворной причинности. |
| Двойное списание после таймаута | Короткая Redis-аренда может истечь до выяснения результата у провайдера. | Устойчивое состояние `SENT → SUCCESS | AMBIGUOUS` блокирует новое списание до сверки. |

## Установка

```bash
npx skills add Dad52/find-solutions --skill find-solutions --agent codex
```

## Как использовать

```text
$find-solutions Наш Android CI всё ещё идёт почти час. Мы уже настроили кэш, распараллелили джобы и перешли на более мощные раннеры. Что можно попробовать за эту неделю, не переделывая весь пайплайн?
```

Полезно сразу написать цель, что уже не сработало, жёсткие ограничения,
дедлайн, доступные ресурсы и какой сигнал будет полезен. Если один факт может
изменить набор решений, скилл спросит о нём один раз. В остальных случаях он
зафиксирует допущение и продолжит.
